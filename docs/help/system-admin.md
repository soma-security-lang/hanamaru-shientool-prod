## 誰が・いつ使うか

システム管理者が「利用者・運用管理」を利用するときの手順です。

## 操作前の確認

ログインし、対象の画面を利用できる権限があることを確認してください。

## 操作手順

1. 管理画面から利用者または運用対象を選びます。
2. 所属・ロール・処理状態などを確認します。
3. 画面で許可される管理操作を行い、結果を確認します。

## 完了の確認

対象者・対象処理と更新結果を確認します。

## 間違えた場合・困ったとき

障害や権限不足の場合は、表示メッセージとリクエストIDを管理担当者へ伝えます。認証情報を送らないでください。
