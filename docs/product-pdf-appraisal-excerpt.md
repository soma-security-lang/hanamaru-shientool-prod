# PDF査定品欄から商品カードへの出典引継ぎ

確定済みの訪問PDFの査定品欄を商品カードの出典にするとき、担当者は原本と照合した該当部分を500文字以内で指定する。複数商品が一つの欄に並んでいても自動分割しない。商品カードは一件ずつ作り、各カードに確定済み抽出IDと確認した該当部分を保存する。

APIは、該当部分が同じ訪問・組織の確定済み査定品欄に含まれるかを保存時に再検証する。照合にはUnicode NFKC正規化、空白の連続を一つにする処理と小文字化を用いる。原本の意味と商品名が一致するかは担当者の判断であり、文字列照合だけで保証したものとして扱わない。PDF抽出失敗や未確定の場合は出典なしの手入力で業務を続けられる。

既存の出典付きカードには確認部分が残っていないため、画面では「旧記録・抜粋未登録」と表示する。旧Web/APIが併存する配備期間のため、APIは抽出IDのみの旧形式も暫定的に受け付ける。新画面では該当部分を必須とし、旧Webが退役した後にサーバー側の必須化を検討する。migration `0064_visit_product_pdf_excerpt.sql` は追加型で、本番適用と公開後の書込み確認は別途実施する。
