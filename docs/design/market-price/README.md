# 買取相場（仮） 画面成果物一覧

## 1. この成果物群の目的

本ディレクトリは、SCR-021「買取相場（仮）」の企画を、画面遷移、必要ページ、各ページの詳細仕様、操作デモへ分解した設計正本である。

バックエンドの決定的URL生成、AI候補選択、90日取得、checkpoint、cache、監視は[Yahoo!落札相場 URL Generator／AIパラメータ補助 詳細設計](./2026-09-09-yahoo-url-generator-and-ai-parameter-assistance.md)を正本とする。

デモHTMLは外部サービスへ接続せず、画面遷移と操作感だけを確認する補助成果物である。正式なローカル実装はNext.js画面、API、Worker、PostgreSQL、URL Generator、AI補助、Yahoo取得、監視を接続済みで、`pnpm local:up:fixture`と`pnpm local:up`を実行入口とする。2026-09-09時点でfixtureの21画面E2EとVertex AI／Yahooの外部provider smokeはPASS、Googleログイン込みの`local:up`受入は秘密設定未配置のためBLOCKED、GCP公開環境には未反映である。デモHTMLではHITLのため1〜5の工程をいつでも直接開けるが、正式画面では本書の実行条件を適用する。

### 1.1 用語方針

- 利用者向け画面では`AI補助`と表示する。
- `Gemini`はVertex AIの実装provider名として、技術設計、設定、監視、監査の内部項目だけで使用する。
- ボタン、見出し、説明、Badge、エラー文言へ`Gemini`を表示しない。

## 3. 必要ページ一覧

SCR-021は独立した業務機能として1画面に数える。ただし利用者の認知上は、次の6つの論理ページへ分ける。

| Page ID | ページ名 | URL表現 | 主目的 | PC | Smartphone |
| --- | --- | --- | --- | --- | --- |
| MP-01 | 検索開始・商品入力 | `/market-price` または `?view=input` | 3つの入力方法から商品条件を作り、対象状態を複数選択する | 左ペイン | 1ページ目 |
| MP-02 | 商品候補・検索条件確認 | `?searchId=<UUID>&view=identify` | AI補助の提案、検索語、商品状態を利用者が確定する | 左＋中央ペイン | 2ページ目 |
| MP-03 | 取得状況 | `?searchId=<UUID>&view=progress` | Workerの状態と復旧方法を確認する | 中央ペイン上部 | 3ページ目 |
| MP-04 | 落札候補確認 | `?searchId=<UUID>&view=candidates` | 同一商品・状態・価格外れ値候補を確認し、除外／復帰する | 中央ペイン | 4ページ目 |
| MP-05 | 相場結果 | `?searchId=<UUID>&view=result` | 除外前後の中央値、最低・最高、除外内訳を確認する | 右ペイン | 5ページ目 |
| MP-06 | 検索履歴 | `?view=history` | 過去結果の閲覧・再検索を行う | 一覧＋詳細 | 独立ページ |

### 3.1 新規Routeを増やさない理由

- SCR-021を単一機能として保つ。
- PCではMP-01、MP-02／04、MP-05を同時表示するため、Routeをページ単位に分割しすぎない。
- Smartphoneでは`view`をブラウザ履歴へ積み、段階遷移として扱う。
- `searchId`を唯一の復元キーとし、商品名、価格、画像情報をURLへ含めない。
- API状態とURLの不一致をcanonical viewへ補正しやすくする。

### 3.2 既存画面への変更

| 対象 | 変更 |
| --- | --- |
| PC Sidebar | 「買取支援AI」の次へ「買取相場」を追加 |
| Mobile Bottom Navigation | ホーム／訪問／買取相場／振り返り／その他へ変更 |
| AppShell page title | `/market-price`を「買取相場」として認識 |
| 管理・システム運用 | kill switch、取得失敗、Parser異常の確認項目を追加 |
| `/knowledge/reference` | 変更しない。金券価格表と買取相場を統合しない |
| 訪問案件 | 変更しない。検索結果を案件へ反映しない |

## 4. ページ間の責任境界

| Page ID | 利用者が確定するもの | システムが確定するもの | 自動遷移 |
| --- | --- | --- | --- |
| MP-01 | 入力方法、画像、既知の商品条件、商品状態の複数選択 | 入力セッションID | しない |
| MP-02 | 商品候補、項目、検索語、除外語、商品状態 | Gemini model・prompt version | しない |
| MP-03 | 再試行・中止の意思 | Job状態、取得範囲、停止理由 | 完了時だけcanonical viewへ置換 |
| MP-04 | 各候補の採用・除外、自動除外候補の復帰 | 正規化値、一致理由、重複、状態別中央値・IQR判定 | しない |
| MP-05 | 結果確認、再検索の開始 | 除外前後の中央値、最低・最高、件数、除外内訳、完全性 | しない |
| MP-06 | 履歴選択、現在条件での再検索 | 保存済みスナップショット | しない |

AI補助の提案と同一商品スコアは利用者の判断材料であり、利用者の確定操作を代替しない。価格外れ値は、同じ状態が5件以上、中央値から20%超、IQR範囲外の全条件を満たす場合に限り初期除外するが、一覧から消さず、利用者が集計へ戻せる。

### 4.1 共通の状態・外れ値契約

- 商品状態は複数選択とし、初期値を「未使用に近い」「目立った傷や汚れなし」「やや傷や汚れあり」の3件とする。
- 最低1件の選択を必須とし、「状態の記載なし」は既定で選択しない。
- 価格外れ値は状態ごとに分離し、5件以上、状態別中央値から20%超、IQR範囲外の全条件で自動除外する。
- 自動除外候補は一覧へ残し、手動復帰と自動判定への復帰を可能にする。
- MP-05は外れ値除外前後の中央値と、キーワード／状態／価格外れ値／手動の除外内訳を表示する。

## 5. PCでの統合表示

PC 1280px以上では、論理ページを次のように統合する。

```text
┌──────────────┬────────────────────────┬──────────────────┐
│ MP-01 条件    │ MP-02 商品候補          │ MP-05 相場結果    │
│ 画像・項目    │ または MP-04 落札候補   │ 統計・完全性      │
│ 検索履歴      │ MP-03 状態Banner        │ 採否に連動        │
└──────────────┴────────────────────────┴──────────────────┘
```

- 左3列：条件、画像、履歴ショートカット。
- 中央5列：現在の判断対象。
- 右4列：確定条件または相場結果。
- ペイン内の選択変更はURLを更新するが、ページ全体を再読込しない。
- 中央の候補採否に応じて右の統計を即時再計算する。

## 6. Smartphoneでの段階表示

```text
MP-01 入力
  → MP-02 条件確認（AI補助は任意）
  → MP-03 取得状況
  → MP-04 落札候補確認
  → MP-05 相場結果

MP-06 履歴
  → 保存済みMP-05
  → 再検索する場合はMP-03
```

- 1画面1目的とし、PCの3ペインを縦積みしない。
- App Barに戻る、画面名、`2 / 5`形式の現在地を表示する。
- 主要操作をBottom Navigation直上のSticky Actionへ置く。
- 候補選択時は画面下部のSticky Summaryで中央値と件数を確認できる。
- 戻る操作で入力値、採否、スクロール位置を復元する。

## 7. 画面状態の共通定義

既存20画面と同じ9共通状態を持つ。

| 状態 | 意味 | 表示契約 |
| --- | --- | --- |
| `initial` | 未入力または未実行 | 次の操作を1つ明示 |
| `loading` | 初回データ取得中 | 骨格表示。偽の進捗率を出さない |
| `empty` | 正常だが対象0件 | 条件変更または新規検索を提示 |
| `success` | 必要データが揃った | 主要操作を有効化 |
| `partial` | 90日境界未達など一部成功 | 取得範囲を明記して利用継続可能 |
| `failure` | 再試行不能または入力不正 | 原因分類と安全な復旧導線 |
| `retry` | 一時障害後の再試行可能 | 明示再試行。自動無限再試行なし |
| `forbidden` | 権限不足 | 本文・条件・価格を表示しない |
| `deleted` | 期限切れ・削除済み | 復元不可と新規検索導線 |
